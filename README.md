# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

This is a ride-pooling MVP. Passengers such as Nusrat, Rafiq and Shirin request rides. Jashim accepts them into **Bullet**, his three-seat Tesla, and each passenger pays their own fare.
